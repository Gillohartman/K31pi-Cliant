# Green Client Tweaks (Fabric, Minecraft 26.1.2)

Client-side mod. Needs Fabric Loader 0.19.2+, Fabric API and Java 25.

Open the menu with **Right Shift**.
Left click = on/off. Right click = bind key, colours, sliders.
Settings are saved in `config/greenmod.json`.

Build: push to GitHub -> Actions -> "Build mod" -> download the `greenmod-jar` artifact.
